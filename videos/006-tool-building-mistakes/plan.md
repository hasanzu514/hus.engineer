# Video 006: I kept rebuilding my engineering tools. Here is what I got wrong

## Status

Idea. Replace with a site-visit video if a suitable visit happens first.

## Viewer

Engineers who want to make small tools for their own work but assume the first version must be complete.

## Viewer promise

The viewer will learn which tool-building mistakes wasted time and how to keep a personal work tool small enough to remain useful.

## Possible stories

- A feature built before the workflow was understood
- A tool that tried to automate too much
- A version that required more maintenance than the task it replaced
- A useful manual approval step that should not have been removed
- Code or interfaces rebuilt several times without changing the real outcome

## Questions to answer

- What did I build first and why was it wrong?
- Which feature sounded useful but was not used?
- What did a simpler version do better?
- How do I decide whether an annoying task deserves a tool?
- What still frustrates me about the current setup?
