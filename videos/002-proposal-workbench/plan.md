# Video 002: I built a tool because my proposals were scattered everywhere

## Status

Idea.

## Viewer

Working engineers who manage proposals, email, meetings, documents and follow-ups without dedicated workflow software.

## Viewer promise

The viewer will see how one repeated work problem became a small internal tool and which parts of the problem did not need AI.

## Central point

The tool began because proposal context was scattered across systems, not because I wanted to build an app.
